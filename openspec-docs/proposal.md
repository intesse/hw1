# proposal.md — мини-трекер учебных задач

## Цель
Собрать автономный мини-трекер учебных задач на неделю: пользователь видит список задач с часами и статусом «готово», может добавлять/удалять/переключать статус, фильтровать список и видеть суммарные часы и процент выполнения по часам.

## Границы (in scope)
- Один HTML-файл `tracker-v2.html` с встроенными CSS и JavaScript.
- Данные задачи: `id`, `title`, `hours`, `done`.
- Стартовый пример: «Чтение» 2 ч done=true; «Практика» 4 ч done=false; «Повторение» 2 ч done=false.
- Добавление, удаление, переключение `done`.
- Валидация названия и часов.
- Фильтр: все / активные / готовые (только видимость списка).
- Метрики: всего часов, выполнено часов, прогресс % по часам.
- Читаемый интерфейс при ширине 390 px.

## Вне scope
- Сервер, сборка, CDN, внешние библиотеки, API-ключи.
- OpenSpec CLI / валидатор (документы готовятся вручную в чате).
- Обязательный localStorage (допустимо как необязательное улучшение).
- Расширение предметной области (календарь, теги, синхронизация).

## Критерий готовности
Одинаковые проверки T1–T5 проходят в браузере; при пустом списке нет NaN/Infinity; прогресс считается по часам, не по числу задач.
