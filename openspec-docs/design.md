# design.md — данные и расчёты

## Модель данных
```text
Task = {
  id: string,
  title: string,   // после trim, непустой
  hours: number,   // 0.5..24, шаг 0.5
  done: boolean
}
```

Состояние UI:
- `tasks: Task[]`
- `filter: "all" | "active" | "done"`
- поля формы `title`, `hours` и строка `error`

## Стартовые данные
| title | hours | done |
|-------|-------|------|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Итого: total=8, doneHours=2, progress=25.

## Расчёты
- `totalHours = Σ task.hours`
- `doneHours = Σ task.hours where done`
- `progress = totalHours == 0 ? 0 : round(100 * doneHours / totalHours)`
- Фильтр не входит в формулы метрик.

## Валидация добавления
1. `title = trim(input)`; если пусто → ошибка.
2. Если hours пусто → ошибка («пустое ≠ 0»).
3. `Number(hours)` конечное; иначе ошибка.
4. Диапазон [0.5, 24]; шаг 0.5 (`hours * 2` целое).
5. При ошибке форма не очищается.

## Представление
- Карточка на узком экране (~390px), без горизонтального скролла.
- Подписи у полей и кнопок.
- Список: чекбокс статуса, название, часы, кнопка удаления.
- Блок метрик всегда по полному массиву `tasks`.

## Ограничения
- Без CDN/библиотек/сервера.
- localStorage не обязателен; если не реализуем — работа только в памяти сессии страницы.
